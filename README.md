# 🦁 LIONE IR — Simulador de Imposto de Renda

Ferramenta desenvolvida no Microsoft Excel para organizar e centralizar informações importantes para a preparação da declaração do Imposto de Renda.

## 📌 Sobre o projeto

O LIONE IR foi desenvolvido como projeto prático de aprendizagem, com foco na organização de dados, validação de informações e criação de uma interface intuitiva no Excel.

A proposta é facilitar o preenchimento e a consulta de informações do contribuinte, reunindo dados relevantes em uma única ferramenta.

## 🎯 Objetivos

- Centralizar informações cadastrais do contribuinte.
- Organizar dados relevantes para a declaração do Imposto de Renda.
- Facilitar o preenchimento e a consulta de informações.
- Aplicar recursos do Excel para estruturar uma ferramenta prática e organizada.

## ⚙️ Tecnologias e recursos

- Microsoft Excel
- Organização e estruturação de dados
- Fórmulas e funções do Excel
- Validação de dados
- Formatação de células e interface visual

*Os recursos listados devem corresponder às funcionalidades efetivamente implementadas na planilha.*

## 📂 Arquivo do projeto

- `Declaração de Imposto de Renda.xlsx` — arquivo Excel para utilização e consulta.

## 🚀 Como utilizar

1. Baixe o arquivo Excel disponível neste repositório.
2. Abra-o no Microsoft Excel.
3. Preencha os campos conforme as orientações da planilha.
4. Revise as informações antes de utilizá-las na preparação da declaração.

## ⚠️ Aviso

Este projeto tem finalidade educacional e organizacional. Não substitui a orientação de um profissional tributário nem a conferência das regras e exigências oficiais aplicáveis ao Imposto de Renda.
